In GRPO, value network (critic) is removed to save memory. To estimate advantages, we sample mulitple responses and do normalization within the group to estimate advantages. Specifically

$$
\begin{align}
\mathbb{A}(i) &= \frac{r_{i} - \mathbb{mean}(r_{1}, r_{2}, \dots, r_{G})}{\mathbb{std}(r_{1}, r_{2}, \dots, r_{G})} \\
\mathbb{J}(\theta) &= \frac{1}{G}\sum_{i=1}^{G}\frac{1}{T_{i}}\sum_{t=0}^{T_{i}-1}\left(\min\left(\frac{\pi_{\theta}(a_{i,t}|s_{i,t})}{\pi_{\theta}^{old}(a_{i,t}|s_{i,t})}\mathbb{A}_{i,t},clip\left(\frac{\pi_{\theta}(a_{i,t}|s_{i,t})}{\pi_{\theta}^{old}(a_{i,t}|s_{i,t})}, 1-\epsilon, 1+\epsilon\right)\mathbb{A}_{i,t}\right)\right)
\end{align}
$$
where $a_{i,t}$ is the token generated at time $t$ in response $i$. All tokens in the response have the same advantage.

## Experiments
[Github project](https://github.com/zhangxuan1918/learn_rlvr)

Due to limit GPU memory (24GB Nvidia RTX 3090), we use QLora for GRPO. More specifically, we

1. load base model in 4bits and freeze it
2. train a Lora adapter (rank=64, dtype=bf16)
3. reward functions are the same as in [Unsloth colab](https://colab.research.google.com/drive/135ced7oHytdxu3N2DNe1Z0kqjyYIkDXp?usp=sharing)
   * format reward:
        * exact: exact format matching, `<reasoning>\n...<\reasoning>\n<answer>\n...<\answer>\n`
        * approximate: allow spaces
        * html tag: reward if there are html tags (`<reasoning>, <\reasoning>, <answer>, <\answer>`) in response
   * correctness reward
      * strict: match the answer
      * fuzzy: answer is integer
4. use train split from GSM8K dataset as prompts
5. evaluate on test split from GSM8K

### Prompt

* Base prompt
   * in system prompt we add detailed instruction (probably too much as we already tell the model the answer should be an integer). We do this because sometimes we notice format issue in the base model
        ```Respond in the following format:
        <reasoning>
        Put your reasoning here.
        </reasoning>
        <answer>
        Put your answer here. The answer should be an integer.
        </answer>```
    * in user prompt, we explicitly state "let's think step by step"
        ```{question}\nLet's think step by step.```. We do this because otherwise the baseline metric is much lower.
* GRPO prompt
    * in system prompt, we use simpler instruction
        ```Respond in the following format:
        <reasoning>
        ...
        </reasoning>
        <answer>
        ...
        </answer>```
    * in user prompt, we just add the question ```{question}``` without think step by step.
